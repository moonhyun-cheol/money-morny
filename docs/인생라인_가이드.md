## 한 줄 요약

| 도구 | 역할 |
|------|------|
| **Google 가게부** | 매일 지출·수입 + **오늘 페이즈** + 목표 저축 vs 실적 |
| **인생라인 탭** | 2026~2040 연도별 순자산·이벤트 로드맵 |
| **분기체크 탭** | D-10, 청약, 카카오 상환 등 분기 할 일 |

**허리띠는 죽을 때까지가 아님.** 2026.07~2031 입주 전이 최대 조임(P0~P3), 입주 후(P4~) 월 여유 ~63만 회복.

```
┌─────────────────────────────────────────────────────────┐
│  [매일] Google Sheets — 한눈에보기                         │
│  · 순자산 · 순저축 · DSR                                  │
│  · 현재 페이즈 (P1 저축전성 등) ← TODAY() 자동            │
│  · 목표 순저축 208만 vs 이번 달 실적                       │
└───────────────────────┬─────────────────────────────────┘
                        │ 같은 스프레드시트
┌───────────────────────▼─────────────────────────────────┐
│  [분기] 분기체크 · 라이프페이즈 · 인생라인 탭               │
│  · 분기 마일스톤 O 체크                                   │
│  · 연도별 순자산 투영 · 입주·출산 이벤트                    │
└───────────────────────┬─────────────────────────────────┘
                        │ config/life_plan.py (원천)
┌───────────────────────▼─────────────────────────────────┐
│  [상세] PC 로컬                                           │
│  · sheets/인생플랜.xlsx — 월예산·고정비·출산 시나리오       │
│  · canvases/life-line.canvas.tsx — Cursor 그래프          │
└─────────────────────────────────────────────────────────┘
```

### 이미 연결돼 있는 것 (배포 시 자동)

`setup.py deploy` 할 때 `config/life_plan.py` 값이 가게부에 들어갑니다.

| 가게부 항목 | life_plan 출처 |
|-------------|----------------|
| 설정 → Person1/2 이름 | `PERSON1_NAME`, `PERSON2_NAME` |
| 목표 순자산·날짜 | `GOAL_NET_WORTH`, `GOAL_DATE` |
| 월 예산 한도 (식비 75만 등) | `MONTHLY_BUDGET` |
| 부채 샘플 (카카오·장학금) | `LIABILITIES` |
| 자산_종목 샘플 (CMA·ISA·청약) | `INVESTMENT_PRODUCTS` |
| 시나리오 월 저축 | `MONTHLY_INVEST_TOTAL` |

## 한눈에보기 — 인생 단계 블록

배포·동기화 후 **한눈에보기** 상단에 아래 블록이 보입니다.

| 행 라벨 | 의미 | 수식/출처 |
|---------|------|-----------|
| **현재 페이즈** | 오늘 날짜 기준 단계 | `라이프페이즈` C열 시작일 `MATCH(TODAY())` |
| **이번 달 할 일** | 해당 페이즈 할 일 | 라이프페이즈 G열 |
| **목표 순저축** | 플랜상 월 저축 합계 (~208만) | `life_plan.MONTHLY_INVEST_TOTAL` |
| **페이즈 목표 여유** | 그 단계에서 기대하는 월 여유 | P1=0, P4~=63만 등 |

**목표 순저축 옆 메모 열:** 이번 달 **순저축**(월간집계)과 비교해 ✅ 달성 / △ N만 부족 표시.

### 하단 핵심 지표 (기존)

순자산 · 순저축 · DSR · 목표 진행률 · 비상자금(개월) + 차트 2개(담당자별 자산, 예산 vs 실적).

### 바로가기 링크 (4번째 줄)

`🗓 인생라인` · `라이프페이즈` · `분기체크` — 클릭 시 해당 탭으로 이동.

## 인생라인 · 라이프페이즈 · 분기체크

### 인생라인

- **출처:** `config/life_timeline.py` → `build_yearly_timeline()`
- **내용:** 2026~2040 연도별 나이, 페이즈, 월 세후·저축·여유, 유동자산, 집 지분, 순자산, 이벤트
- **용도:** "2031 입주 때 순자산 얼마나 되나?" 장기 점검

### 라이프페이즈

**상단 표 (날짜 조회용)**

| 열 | 내용 |
|----|------|
| A | 단계 ID (P0~P6) |
| B | 이름 |
| C | 시작일 |
| D | 종료일 |
| E | 허리띠 |
| F | 월 여유(원) |
| G | 이번 달 할 일 |

한눈에보기 수식이 **이 표의 C열**을 참조합니다. 시작일은 **오름차순**이어야 합니다.

**하단 요약:** `LIFE_PHASES` 텍스트 기간·요약·할 일 (사람이 읽기용).

### 분기체크

| 열 | 예시 |
|----|------|
| 분기 | 2027-Q1 |
| 영역 | 비자 / 재무 / 주택 |
| 할 일 | D-10 연장 |
| 메모 | TOPIK 6급 |
| 완료 | 직접 `O` 입력 |

분기마다 해당 행만 확인하면 됩니다.

## 매일·주·분기·갱신 루틴

### 매일 (1~3분)

1. `지출` / `수입` 입력
2. `한눈에보기` 열기
   - 현재 페이즈 확인 (지금 허리띠 조인 구간인지)
   - 목표 순저축 vs 순저축 (P1이면 208만에 가깝게)

### 주 1회

- **재무관리 → 📊 갱신 → 시세+환율+일별자산** (또는 09:00 자동)
- `자산_종목` 매수·입금 반영

### 분기 1회 (15분)

1. `분기체크` — 이번 분기 행 `O` 체크
2. `인생라인` — 올해 순자산 열이 감각과 맞는지
3. (필요 시) `설정` 예산 한도 조정

### 숫자·플랜 갱신 (집값·소득 바뀔 때)

```powershell
# 1. 코드 수정
#    config/life_plan.py

# 2. Excel 재생성 (선택)
python scripts/build_life_plan_xlsx.py
python scripts/build_life_timeline_xlsx.py

# 3. Google 시트 반영
python scripts/sync_life_sheets.py --id=스프레드시트ID
```

한눈에보기 페이즈 블록까지 새로 만들려면 `python setup.py deploy` (새 시트) 또는 기존 시트에서 한눈에보기 수동 복사.

## 처음 배포 vs 기존 시트 업데이트

### A. 처음 (새 Google 시트)

```powershell
git clone https://github.com/moonhyun-cheol/money-morny.git
cd money-morny
pip install -r requirements.txt
# config/credentials.json 준비
python setup.py deploy
```

→ **22개 탭** 포함 (인생라인 3개 + 한눈에보기 페이즈 블록).

배포 직후: [사용설명서 — 배포 직후 10분 설정](사용설명서.md#배포-직후-10분-설정)

### B. 이미 쓰던 가게부에 탭만 추가

1. Spreadsheet URL에서 ID 복사  
   `https://docs.google.com/spreadsheets/d/【여기】/edit`

2. PC에서 (credentials.json 필요):

```powershell
python scripts/sync_life_sheets.py --id=【스프레드시트ID】
```

→ `인생라인` · `라이프페이즈` · `분기체크` 3탭 추가·덮어쓰기.

> **한눈에보기 페이즈 블록**은 sync만으로는 안 붙습니다.  
> 새 deploy 시트에서 복사하거나, 재배포 후 데이터 이전을 권장합니다.

### C. 집에서 pull만 (입력만 할 때)

```powershell
git pull
```

Spreadsheet **URL**만 즐겨찾기면 Git 없이도 폰·태블릿에서 입력 가능.

## 숫자 바꿀 때 (life_plan.py)

자주 바꾸는 항목:

| 변수 | 예 |
|------|-----|
| `NET_INCOME_P1/P2` | 세후 급여 |
| `FIXED_*` | 고정비 항목 |
| `SAVE_ISA`, `SAVE_HOUSE` | 저축 배분 |
| `GOAL_NET_WORTH`, `GOAL_DATE` | 목표 |
| `MORTGAGE_PRINCIPAL` | 디딤돌 대출 |

수정 후:

1. `python scripts/build_life_plan_xlsx.py` (로컬 Excel)
2. `python scripts/sync_life_sheets.py --id=...` (Google 인생 탭)
3. 가게부 **설정** 시트 예산·목표 수동 맞추기 (deploy 안 다시 했으면)

`LIFE_PHASE_RANGES` — Google `TODAY()` 페이즈 조회용 날짜 구간. 입주·혼인 일정 바뀌면 여기도 수정.

## FAQ

### Q. 한눈에보기에 "현재 페이즈"가 `#N/A` 나와요

- `라이프페이즈` 탭이 없거나 C열 시작일이 비어 있음 → `sync_life_sheets.py` 실행
- 오늘이 2041 이후면 범위 밖 → `LIFE_PHASE_RANGES` 연장

### Q. 목표 순저축 208만인데 순저축이 다르게 나와요

- **순저축** = 수입 − 지출 (가게부 실적)
- **목표** = 플랜상 ISA+집마련+연금+비자 합 (자동이체 기준)
- P0(7월)은 목표가 다름 — 7월만 예외

### Q. 인생라인 순자산과 가게부 순자산이 달라요

- 인생라인 = **모델 투영** (이자 2.5%·소득 4% 성장 가정)
- 가게부 = **실제** 자산_종목 − 부채
- 둘을 비교해 "플랜 대비 앞서가/뒤처짐" 판단용

### Q. 배우자 폰에서만 쓰려면?

- Spreadsheet URL 공유 (편집자)
- Git·Python 불필요

### Q. gid 링크가 안 먹어요

- 시트 추가·삭제 후 **gid(시트 ID)** 가 바뀔 수 있음
- 탭 이름으로 직접 이동하거나 재배포
