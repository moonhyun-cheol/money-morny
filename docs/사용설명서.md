# 재무관리 시스템 — 사용 설명서

## 이 시스템으로 할 수 있는 것

| 영역 | 기능 |
|------|------|
| **일상** | 2인 수입·지출 매일 기록, 카테고리별 **예산 vs 실적** |
| **투자** | ISA·연금·주식·해외(USD/CNY) 종목별 평가, **담당자**별 자산 |
| **부채** | 대출 등록, DSR·월상환, 순자산(자산−부채) |
| **계획** | 목표 순자산·예상 달성, 시나리오(지금 vs 1년 후) |
| **세금·만기** | ISA/연금 한도, 만기 D-day 알림 |
| **자동화** | 9시 시세·환율·일별 스냅샷, 23시 월말 리포트 |

**시작 화면은 항상 `한눈에보기` 탭**입니다. 상세 숫자는 마지막 탭 `대시보드(상세 KPI)`에서 확인합니다.

## 처음 배포하기 (0→1)

아직 Google Sheets에 **한 번도 올리지 않았다면** 아래 순서대로 진행하세요.  
**총 소요: OAuth 설정 5~10분 + 배포 1~2분**

### 준비물

| 항목 | 설명 |
|------|------|
| PC | Windows / Mac (배포할 때만 필요) |
| Python | **3.10 이상** — [python.org](https://www.python.org/downloads/) |
| Google 계정 | Gmail 또는 Google Workspace |
| 인터넷 | OAuth·API 호출용 |

### Step 0. 프로젝트 폴더 확인

```
c:\Users\Temp\Desktop\현철\코딩연습\재무관리 프로그램\
├── setup.py          ← 배포 실행 파일
├── requirements.txt
├── config\
│   └── credentials.json   ← Step 2에서 직접 넣음
├── deploy\           ← 시트 생성 코드
└── apps-script\      ← Google 메뉴·자동화 코드
```

### Step 1. Google Cloud 프로젝트 만들기

1. [Google Cloud Console](https://console.cloud.google.com) 접속
2. 상단 **프로젝트 선택 → 새 프로젝트** (이름 예: `재무관리`)
3. 생성된 프로젝트를 선택한 상태로 진행

### Step 2. API 4개 켜기

[API 라이브러리](https://console.cloud.google.com/apis/library)에서 검색 후 **사용** 클릭:

1. **Google Sheets API**
2. **Google Docs API**
3. **Google Drive API**
4. **Google Apps Script API**

> 하나라도 빠지면 배포 중 `403 API not enabled` 오류가 납니다.

### Step 3. OAuth 동의 화면

1. **API 및 서비스 → OAuth 동의 화면**
2. User Type: **외부** (개인 Gmail OK)
3. 앱 이름: `재무관리` (아무 이름 가능)
4. 사용자 지원 이메일·개발자 연락처 입력 → 저장
5. **범위(Scopes)** 단계는 건너뛰어도 됨
6. **테스트 사용자** → **+ ADD USERS** → **배포에 쓸 Gmail 주소** 추가  
   → 저장

> 테스트 모드에서는 **등록한 Gmail만** 로그인할 수 있습니다.

### Step 4. OAuth 클라이언트 ID (데스크톱)

1. **API 및 서비스 → 사용자 인증 정보**
2. **+ 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
3. 애플리케이션 유형: **데스크톱 앱**
4. 이름: `재무관리-local` → 만들기
5. **JSON 다운로드**
6. 다운로드한 파일을 아래 경로로 복사·이름 변경:

```
재무관리 프로그램\config\credentials.json
```

`credentials.json.example`은 참고용이며, **실제 JSON 내용**으로 교체해야 합니다.

### Step 5. Python 패키지 설치

**PowerShell** 또는 **명령 프롬프트**에서:

```powershell
cd "c:\Users\Temp\Desktop\현철\코딩연습\재무관리 프로그램"
pip install -r requirements.txt
```

Python이 `python`이 아니라 `py`로만 잡히면:

```powershell
py -3 -m pip install -r requirements.txt
```

### Step 6. 배포 실행

```powershell
cd "c:\Users\Temp\Desktop\현철\코딩연습\재무관리 프로그램"
python setup.py deploy
```

(`python`이 안 되면 `py -3 setup.py deploy`)

**진행 순서 (자동):**

| 단계 | 동작 |
|------|------|
| OAuth | 브라우저 열림 → Google 로그인 → **권한 허용** |
| 1/4 | Google Docs 월간 리포트 **템플릿** 생성 |
| 2/4 | Google Sheets **스프레드시트 19탭** 생성 |
| 3/4 | Apps Script 코드 업로드 (메뉴·시세·자동화) |
| 4/4 | URL 출력 |

**성공 시 터미널 예시:**

```
============================================================
재무관리 시스템이 생성되었습니다.
============================================================
  Spreadsheet : https://docs.google.com/spreadsheets/d/xxxxx/edit
  Docs 템플릿 : https://docs.google.com/document/d/xxxxx/edit
  Apps Script : https://script.google.com/home/projects/xxxxx/edit
```

1. **Spreadsheet URL**을 메모장·즐겨찾기에 저장하세요.  
   → 이후 매일 이 링크만 열면 됩니다.

2. `config\token.json`이 자동 생성됩니다.  
   → 같은 PC에서 **재배포**할 때 브라우저 없이 로그인될 수 있습니다.

### Step 7. 스프레드시트 첫 실행

1. 출력된 **Spreadsheet URL** 클릭
2. **F5 새로고침** (메뉴가 안 보일 때)
3. 상단에 **「재무관리」** 메뉴 확인
4. **재무관리 → ⚙ 트리거 설치 (자동)** 클릭
5. **Apps Script 권한** 최초 1회 승인 (Google 보안 경고 → 고급 → 허용)

> 트리거를 설치해야 **매일 9시 시세·일별 자산**, **23시 월말**이 동작합니다.

## 배포 직후 10분 설정

### 1. `설정` 시트

| 항목 | 예시 | 설명 |
|------|------|------|
| Person1 이름 | `현철` | 수입·지출·**담당자** 열과 **일치**해야 함 |
| Person2 이름 | `○○` | 배우자 이름 |
| 목표 순자산 | `100000000` | 원 단위 (1억) |
| 추세 계산 개월수 | `6` | 목표 달성 예측용 |
| **예산 (월 한도)** | 식비 60만 등 | 카테고리별 지출 상한 |

### 2. `자산_종목` 시트

- 샘플 4행 참고 후 본인 계좌·종목으로 수정
- **C열 담당자** = 설정의 Person1/Person2 이름 또는 `공동`
- **계좌명** 규칙: `사람1-키움ISA` (같은 통장은 같은 이름)

### 3. `부채` 시트 (대출 있으면)

- 담보대출·신용대출 등 **현재잔액·월상환액** 입력

### 4. 시세 첫 갱신

**재무관리 → 📊 갱신 → 시세+환율+일별자산**

- 해외 주식·환율 반영
- `자산_일별이력`에 **오늘** 첫 행 기록

### 5. `한눈에보기` 확인

- 순자산·순저축·DSR·목표·**비상자금(개월)** KPI
- 담당자별 자산 도넛, 예산 vs 실적 차트

## 자산_종목 입력 가이드

### 열 구조 (A~N)

| 열 | 필드 | 입력 팁 |
|----|------|---------|
| A | 계좌유형 | 드롭다운 (ISA, 적금, 주식…) |
| B | 계좌명 | `사람1-키움ISA` 형식 권장 |
| **C** | **담당자** | 설정 B2/B3 이름 또는 `공동` |
| D | 티커 | `005930`, `VOO` (없으면 비움) |
| E | 종목명 | 표시용 |
| F | 수량 | 주식=주수, 적금=1 |
| G | 평단가 | 해당 **통화** 기준 |
| H | 현재가 | 시세 갱신 또는 수동 |
| I | 평가금액(원) | **자동** = F×H×환율 |
| L | 시장 | KS / KQ / US / CN |
| M | 통화 | KRW / USD / CNY |

### 국내 주식 예

| A | B | C | D | L | M |
|---|---|---|---|---|---|
| ISA | 사람1-키움ISA | 사람1 | 005930 | KS | KRW |

### 미국 ETF 예

| D | L | M | G·H 단위 |
|---|---|---|----------|
| VOO | US | USD | 달러 |

### 적금·예금 예

| A | D | F | H | M |
|---|---|---|---|---|
| 적금 | (비움) | 1 | 5000000 | KRW |

> 수량=1, 현재가=잔액(원)으로 두면 됩니다.

## 예산 · 비상자금 · 목표

### 예산 vs 실적

1. **`설정`** 하단 **「예산 (월 한도)」** — 카테고리별 월 한도(원)
2. **`지출`**에 매일 입력
3. **`월간집계`** — 한도 / 실적 / 달성률 자동 계산
4. **`한눈에보기`** — 예산 vs 실적 차트  
   - 달성률 80%↑ 노랑, 100%↑ 빨강 배경

### 비상자금 (개월)

```
(현금 + CMA 평가액) ÷ 이번 달 총 지출
```

- **`한눈에보기`** KPI에 **N개월** 표시
- 일반적으로 **3~6개월** 이상을 목표로 많이 둡니다

### 목표 순자산 · 예상 달성

- **`설정`** B4 목표 금액
- **`대시보드(상세 KPI)`** — 목표 진행률, 예상 달성 개월  
  (최근 N개월 순자산 증가 평균 기반, N=`설정` B6)

## 자산 이동 · 템플릿

### 자산_이동 시트

| 열 | 내용 |
|----|------|
| 이동유형 | 계좌간이동, ISA만기→연금, 아파트구매… |
| 출발/도착 | 계좌유형 + 계좌명 |
| 금액 | 원 |
| 상태 | **예정** → 메뉴 실행 → **완료** |

**실행:** 재무관리 → 💸 자산 이동 → **예정 전체 실행**

### 이동_템플릿

1. `이동_템플릿` 시트에서 행 번호 확인
2. 메뉴 **템플릿 적용** → `행번호,금액` 입력 (예: `2,20000000`)
3. `자산_이동`에 자동 입력 → **실행**

### 아파트 구매 팁

1. `부채`에 담보대출 먼저 등록
2. `자산_이동` — 아파트구매, 자기자금만 이동
3. `자산_종목`에 부동산 행 추가·금액 수정

## 재무관리 메뉴 (Apps Script)

스프레드시트 상단 **「재무관리」**:

| 서브메뉴 | 항목 | 용도 |

## 문제 해결 (FAQ)

### 「재무관리」메뉴가 없어요

1. Spreadsheet **F5 새로고침**
2. [Apps Script URL](배포 시 출력) → `Code.gs` → 함수 `onOpen` 선택 → **실행**
3. 권한 승인 후 시트로 돌아와 새로고침

### OAuth: access blocked / 403

- Cloud Console → OAuth → **테스트 사용자**에 본인 Gmail 추가
- API 4개 모두 **사용** 설정 확인

### credentials.json이 없다

```
FileNotFoundError: credentials.json이 없습니다
```

→ Step 4 다시: JSON을 `config\credentials.json`으로 저장

### 시세 갱신 실패

- 티커·시장(US/KS)·통화(USD/KRW) 확인
- 실패 종목은 **H열 현재가** 수동 입력

### 담당자별 금액·차트가 0

- **`설정` B2/B3 이름**과 **`자산_종목` C열**이 **완전히 동일**한지 확인  
  (예: `사람1` ≠ `사람 1`)

### 순자산·DSR이 이상해요

- `부채` D열 **현재잔액** 확인
- `자산_종목` I열(원화 평가) 비어 있으면 **시세+환율 갱신**

### deploy를 다시 실행하면?

→ **새 스프레드시트**가 생깁니다. 기존 데이터는 **복사되지 않습니다**.  
Drive에서 기존 파일 백업 후 진행하세요.

## 보안 · 재배포 주의

**절대 공유·Git 업로드 금지:**

- `config/credentials.json` — OAuth 클라이언트
- `config/token.json` — 로그인 토큰

**재배포 (`python setup.py deploy`):**

- 새 Sheets + 새 Docs + 새 Script 생성
- 기존 URL과 **별개** 파일

**코드만 수정했을 때:**

- Apps Script 편집기에서 `.gs` 파일 수동 붙여넣기 가능
- 시트 구조 변경은 **재배포**가 필요
