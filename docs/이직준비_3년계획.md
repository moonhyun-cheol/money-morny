## 의류·커머스 도메인 활용

자격 로드맵은 업종 무관으로 유지한다. **포지셔닝·포트폴리오·지원처**만 의류 경력을 살린다.

| | 내용 |
|--|------|
| **강점** | 반품·발주(PO)·샘플재고·Looka 등 **운영 실무 + 자동화** 경험. 비전공 이직에서 도메인이 비싸다 |
| **포장** | “의류=비IT”가 아니라 **도메인 전문가 + 데이터/자동화** |
| **이력서 한 줄 예** | `의류/이커머스 운영 자동화 · 반품·발주·재고 direct command / 데이터 연동` |
| **잘 맞는 타깃** | 패션·리테일·이커머스·물류의 데이터/리포팅/운영툴/사내 AI·봇 |
| **덜 맞는 타깃** | 순수 ML 리서치·빅테크 AI만 (도메인 가중 ↓, CS·코딩 비중 ↑) |

**포트폴리오:** 새 토이 프로젝트보다, 이미 한 의/발주/재고/자동화 사례를 **한글로 설명 가능**하게 정리하는 쪽을 우선한다.
