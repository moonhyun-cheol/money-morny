## 자산_종목 (A~N)

| 열 | 필드 |
|----|------|
| A | 계좌유형 |
| B | 계좌명 (예: `사람1-KB적금`) |
| **C** | **담당자** — `설정!B2`/`B3` 이름 또는 `공동` |
| D~E | 티커, 종목명 |
| F~H | 수량, 평단가, 현재가 (통화 기준) |
| I | 평가금액(원) = F×H×N |
| J | 평가손익(원) |
| K | 비중% |
| L | 시장 KS/KQ/US/CN |
| M | 통화 **KRW / USD / CNY** |
| N | 적용환율 ← `환율` 시트 |

### 계좌명 규칙

- 한 통장에 종목 여러 개 → **같은 계좌명**으로 여러 행 입력
- 권장: `[담당자]-[은행/증권]-[용도]` (예: `사람1-키움ISA`, `사람2-신한적금`)

## 계좌목록 (시트 17)

- A~E: `QUERY`로 담당자·계좌유형·계좌명·종목수·총평가 자동 집계
- F: 비중% (`ARRAYFORMULA`)
- H~I: 담당자별 합계 (설정 이름 연동)
- H~I (하단): Person2 계좌유형별 차트 데이터
- **Person1·Person2 계좌유형별 막대 차트** 포함

## 자산_일별이력 (시트 18)

| 열 | 필드 |
|----|------|
| A | 날짜 |
| B | Person1 자산 (`설정!B2` 이름) |
| C | Person2 자산 (`설정!B3` 이름) |
| D | 공동 |
| E | 합계 (B+C+D) |

- **매일 09:00** `시세+환율 갱신` 후 Apps Script가 자동 기록
- **오늘 날짜** 행이 있으면 **덮어쓰기** → 항상 최신 평가 반영
- 메뉴 **「일별 자산 스냅샷」**으로 수동 실행 가능
